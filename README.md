A backport of the popular Just Hammers mod to Minecraft 1.12.2.

---

## Features

- **5 Hammer Types** - Basic, Impact, Reinforced, Reinforced Impact, Destructor
- **4 Base Materials** - Iron, Stone, Diamond, Golden
- **Additional Materials** - Netherite (conditional), Copper (conditional)
- **Core Crafting System** - Craft advanced hammers using special cores
- **Direction Detection** - Mining direction works like Techguns
- **Sneak Mode** - Hold Shift to mine single blocks
- **Lava Immunity** - Netherite items don't burn in lava

---

## Hammer Types

| Type | Range | Depth | Area |
|------|-------|-------|------|
| Basic | 1 | 1 | 3x3x1 |
| Impact | 1 | 3 | 3x3x3 |
| Reinforced | 2 | 1 | 5x5x1 |
| Reinforced Impact | 2 | 3 | 5x5x3 |
| Destructor | 2 | 5 | 5x5x5 |

## Installation

1. Install Forge for 1.12.2
2. Drop `justhammersbackport-*.jar` into `.minecraft/mods`
3. Launch Minecraft

---

## Controls

- **Left Click** - Area mining
- **Shift + Left Click** - Single block mining
