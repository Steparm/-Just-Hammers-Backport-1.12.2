# Changelog

## 1.9.2
- Initial release for Minecraft 1.12.2
- Added 4 tiers of hammers: Iron, Stone, Diamond, Golden
- Added 5 types: Basic, Impact, Reinforced, Reinforced Impact, Destructor
- Added Netherite and Copper variants
- Added cores system for crafting advanced hammers
- Added lava immunity for Netherite items
- Added custom tooltips with durability stars
- Added advancement: "Won't The Butt Stick Together?"
